Instructions:

  • You must solve 9 puzzles of increasing difficulty: 3 Easy (3×3), 3 Medium (larger grids, multi-step rules), and 3 Hard (complex reasoning, variable grid sizes).
  • For each puzzle, observe the Test input grid on the left and the Task demonstration examples above.
  • Deduce the underlying pattern or rule from the examples.
  • Apply that rule to the Test input grid to generate the correct output grid on the right.
  • You can resize the grid, pick colors from the bottom palette, edit individual cells, or use the flood-fill tool.
  • Your time is recorded, but you can jump back and forth between tasks as your partial progress is saved!
